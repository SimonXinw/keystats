# 按键统计

Windows 上的按键计数器。它只记录你按下了哪个键、点了哪颗鼠标键、当时前台是哪个程序。它不注册任何全局快捷键，也不拦截、不修改、不重放你的输入。

打英雄联盟时可以用，其他软件也一样。统计按前台进程分开。

## 为什么用 Rust，而不是 AutoHotkey

AutoHotkey 适合写自己的快捷键。这个需求正好相反：不能占用任何按键，也不能在钩子里做重活。

Rust 编出来是原生程序，键盘和鼠标钩子里只做一次判断，然后立刻把输入交回系统。计数放到后面的线程。界面、暂停、导出和退出时的资源释放都在程序自己手里，不依赖一个常驻脚本解释器。

## 它记什么

- 键盘：每个键单独计数。`Q` 和 `W` 分开，左 Shift 和右 Shift 分开，左右 Ctrl、左右 Alt 也分开。
- 鼠标：左键、右键、中键、两个侧键、滚轮上下、横向滚轮，各自计数。
- 进程：记按键发生时的前台程序，例如 `League of Legends.exe`。
- 按住一个键不连发计数。松开再按下，才会再记一次。
- 鼠标移动不计数。

暂停之后，新的按键不再进入统计。已经进队列的那一下还会记完。清零会丢掉当前内存里的数据，已经导出的文件不动。

## 界面

- **开始 / 继续**：开始记录，或从暂停里接着记。
- **暂停**：停止记录，数字保留。
- **清零**：清空当前统计。关掉再打开也不会把这次清掉的次数找回来。
- **导出表格**：保存为 CSV，编码是 UTF-8（带 BOM，Excel 能直接打开中文）。导出的是屏幕上正在看的数字。
- **计入本程序**：默认打开，本窗口上的按键和点击也会计入合计、表格和导出。按钮显示「取消计入本程序」，点一下就不再计入，按钮变成「打开计入本程序」。
- **近一分钟**：合计下面的数字，只算最近 60 秒。旁边的平均是这次从开始到现在的每分钟次数。
- 关掉窗口后，次数保存在本机。下次打开是暂停状态，点「继续」接着记。
- **按键明细**：每个进程里的每个键。
- **进程汇总**：每个进程的键盘次数、鼠标次数和合计。
- **按键合计**：同一个键在所有进程里的次数加在一起，按次数从高到低排，并显示占当前列表的比例。筛选对这一页同样生效。
- **键位热力**：左边是标准全尺寸键盘，右边是普通鼠标。颜色从深青到暖黄，越暖次数越多，悬停可看具体次数。两个侧键画在鼠标左侧。
  - 按住的键整颗亮起并下沉，键缝透出柔光，松开后渐暗。粘滞键激活期间一直亮着。
  - **配色**：可以改「次数少 / 中 / 多」三段渐变和「按下」的颜色，用取色板或输入 `#RRGGBB`。改动立刻生效，并保存在本机。
- 筛选框可以按进程名或按键名过滤。

本窗口自己的点击也会记在 `keystats.exe` 下面。

如果某个程序以管理员身份运行，而本程序不是，进程名可能显示成 `进程 1234`。需要看名字时，用管理员身份启动本程序即可。平时打游戏不需要这样做。

英雄联盟开着反作弊时，系统可能不把游戏里的输入交给普通钩子。这时别的软件仍然能统计，游戏里可能统计不到。本程序不会尝试绕过反作弊。

## 打包成 exe

电脑上需要已安装 Rust。在项目目录打开 PowerShell，执行：

```powershell
.\build.ps1
```

第一次会下载依赖，需要联网，可能要几分钟。完成后文件在：

```text
dist\keystats.exe
```

把这个 exe 复制到别的 Windows 电脑就能直接双击运行，不需要再装 Rust。

手动打包是同一条命令：

```powershell
cargo build --release
copy target\release\keystats.exe dist\keystats.exe
```

## 开发时运行

```powershell
cargo run
```

单元测试：

```powershell
cargo test
```

## 性能

- 钩子线程只在真正的按下、松开、滚轮时做很少的工作。鼠标移动只做一次判断就放行。
- 存盘在界面线程，统计进行时大约每 5 秒一次，再加上暂停、清零和退出。钩子里不写文件。
- 重复打开不会再装一套钩子，只会把已经开着的窗口带到前面。
- 计数在另一条低优先级线程里完成，通道有上限。满了就丢掉这一下并在界面底部提示，不会无限占内存，也不会堵住你的键鼠。
- 没有按键历史列表，只保留「进程 + 按键 → 次数」。清零或退出时会释放这些数据。
- 退出程序会卸掉钩子并结束后台线程。

程序空闲时几乎不占 CPU。开着打游戏是预期用法。
